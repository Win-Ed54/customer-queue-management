#Customer Queque Managemente

A simple customer queque managemente system built with HTML, CSS and JavaScript

##Description

This project allow user to register customer tickets, assign priority attend the next customer, cancel tickets, and view basic queue statisitics.

##Features

-Register customer tickets
-Assign priority to customer
-Display pending tickets
-Attend the next ticket
-Cancel tickets
-Show attended ticket history
-Display basic statistics

##Technologies

-HTML
-CSS
-JavaScript
